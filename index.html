⚡ Preset

📌 Cara Cepat

1. Tambahkan komponen.
2. Untuk kabel, cukup klik terminal pertama lalu klik terminal kedua. Bisa juga tekan-tahan lalu tarik. Area terminal diperbesar agar lebih mudah disentuh.
3. Kabel tetap menempel ketika komponen dipindahkan.
4. Klik kabel untuk memilih. Tekan Delete untuk menghapus.
5. Klik dua kali badan komponen untuk memutar 90°.
6. Klik sakelar untuk membuka/menutup.
7. Klik ▶ Jalankan.

📘 LKPD Interaktif — Listrik Dinamis

Tujuan Pembelajaran

Peserta didik dapat menjelaskan Hukum Ohm, membedakan rangkaian seri dan paralel, serta memasang amperemeter secara seri dan voltmeter secara paralel.
